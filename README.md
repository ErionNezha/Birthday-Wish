# 🎉 Urimi i Ditëlindjes

Faqe interaktive për urimin e ditëlindjes — ndiz dritat, dëgjo muzikën, zbukuro me balona, shiko tortën dhe ndiz qirinjtë, pastaj lexo urimin e fshehur. Ndërtuar me HTML, CSS dhe JavaScript (jQuery).

## 🚀 Si ta hapësh

Hap `index.html` në browser — shtyp butonat në rreshtin poshtë sipas renditjes: "Turn On Lights", "Play Music", "Let's Decorate", "Fly With Balloons", "Most Delicious Cake Ever", "Light Candle", "Happy Birthday" dhe "A mesage for you".
